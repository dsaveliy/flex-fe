# Flex — Mobile Frontend Application

Фронтенд-часть мобильного приложения **Flex** — адаптивного Progressing Web App (PWA) / Mobile-first веб-клиента для смартфонов, объединяющего классический мобильный банкинг и операции с криптовалютой.

---

## 1. Описание проекта
Мобильный интерфейс **Flex** спроектирован по принципам **Mobile-First UX/UI**. Приложение адаптировано под сенсорное управление (touch-friendly) на экранах iOS и Android: поддерживает нативные жесты (bottom sheets, pull-to-refresh), интеграцию с мобильной камерой для быстрого сканирования документов при прохождении KYC и оптимизировано для работы при нестабильном мобильном интернет-соединении.

---

## 2. Стек используемых технологий
* **Фреймворк:** React 18 (Mobile-first SPA / PWA)
* **Язык:** TypeScript
* **Сборщик:** Vite
* **Стилизация:** Tailwind CSS
* **UI-компоненты:** shadcn/ui + Lucide Icons (адаптированные мобильные шторки `Drawer`, `Sheet`, уведомители `Toast`)
* **Управление состоянием и запросами:** TanStack Query (React Query) — для кэширования котировок и фонового обновления данных
* **Маршрутизация:** React Router v6
* **Веб-сервер раздачи статики:** Nginx (внутри Docker-контейнера)

---

## 3. Структура экранов и пользовательские сценарии (UX Flow)

### Главный экран (Дашборд)
* **Карточка баланса:** Центральный виджет с суммарным балансом, обьединяющий фиатные счета (BYN, USD) и криптокошельки (BTC, ETH).
* **Быстрые действия:** Кнопки «Перевести», «Пополнить», «Обменять», «Оплатить».
* **Лента последних транзакций:** Компактная история операций с фильтрацией.

### Переводы и Обмен
* **P2P-переводы:** Ввод номера телефона с выбором контакта из мобильной книги.
* **Мобильный обмен (Crypto <-> Fiat):** Быстрый калькулятор конвертации с отображением текущего курса из `exchange_rates` в реальном времени.
* **Крипто-эквайринг:** Симуляция оплаты с карты с автоматической конвертацией криптобаланса в фиат.

### Профиль и Верификация (KYC)
* **Мобильный KYC-сканер:** Форма с возможностью сделать фото паспорта и селфи прямо с камеры смартфона.
* **Безопасность:** Быстрый вход по PIN-коду и настройка биометрии.
