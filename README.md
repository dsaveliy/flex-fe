# Flex — Mobile Frontend Application (Mobile-First)

Фронтенд-часть мобильного приложения **Flex** — адаптивного Progressing Web App (PWA) / Mobile-first веб-клиента для смартфонов.

---

## 1. Описание проекта
Мобильный интерфейс **Flex** спроектирован по принципам **Mobile-First UX/UI**: крупная touch-панель управления, удобная адаптация под экраны iOS и Android, поддержка нативных жестов (bottom sheets, pull-to-refresh), интеграция с мобильной камерой для KYC и поддержка offline-кэширования.

---

## 2. Стек используемых технологий
* **Фреймворк:** React (Mobile-first SPA / PWA)
* **Язык:** TypeScript
* **Сборщик:** Vite
* **Стилизация:** Tailwind CSS + shadcn/ui (мобильные компоненты: Drawer, Sheet, Toast)
* **Управление состоянием и запросами:** TanStack Query (React Query)
* **Веб-сервер раздачи статики:** Nginx
