# Flex — карты и фильтры операций

За основу взяли [мобильный макет Cards в Figma](https://www.figma.com/design/knAh7OLAu86a7jYCaV6hBe/flex?node-id=10-370). Ниже описаны состояния, которые добавили к этому макету. Снимки сделаны в веб-версии на демонстрационной базе.

## Операции по карте

История расположена под действиями выбранной карты. В заголовке блока показываем выбранный период и кнопку-воронку. Поле поиска по описанию находится над результатами. При активных фильтрах рядом с полем доступен сброс. Смена карты сохраняет период и текст поиска и обновляет список для новой карты.

| Состояние | Что видит пользователь |
| --- | --- |
| [Выбор периода](screenshots/report-6-2/01-period-menu.png) | Меню «Неделя», «Месяц», «3 месяца», «Год», «Всё время» с отметкой текущего значения. |
| [Применение двух критериев](screenshots/report-6-2/02-combined-filters.png) | Подпись периода, текст поиска, действие сброса и операции, которые подходят обоим критериям. |
| [Пустой результат](screenshots/report-6-2/03-empty-results.png) | Сообщение об отсутствии совпадений, действующие фильтры и доступный сброс. |
| [Сброс](screenshots/report-6-2/04-reset-filters.png) | Исходный список по той же карте, пустое поле и период «Всё время». |

Пока запрос загружается, на месте строк показываем скелетон. При сетевой ошибке доступен повтор. Если карта недоступна, показываем сообщение о недоступности её истории.

## Привязанные карты

Экран открывается через «Карты» → «+» → «Привязанные карты». Список показывает название карты и маскированный номер. При пустом списке доступно добавление. Для привязки используется отдельная форма. Название меняется прямо в строке карты. Перед отвязкой показываем последние четыре цифры, действие подтверждения и отмену.
