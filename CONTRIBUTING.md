# Участие в Flex

Общие правила команды и документация находятся в [flex-be/CONTRIBUTING.md](https://github.com/dsaveliy/flex-be/blob/main/CONTRIBUTING.md). Работаем через короткие ветки и PR с одобрением другого участника. Требования к клиентскому коду — [CLAUDE.md](CLAUDE.md).

Перед PR: `npm ci`, `npm run typecheck`, `npx expo export --platform web`. API и документация меняются совместно с серверной парой.
